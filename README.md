# IBEX Global Service – Travel Agency Website

A WordPress-based website project for a travel agency, designed to present travel services, destinations, and tour information through a professional and user-friendly online platform.

## Project Overview

**IBEX Global Service** is a Travel Agency Website currently under development using WordPress.

The goal is to create an accessible and responsive website where visitors can explore travel-related services, discover destinations, and contact the agency for further information.

## Project Status

**In Development**

The website is currently being developed. Features and design elements will be documented and updated as the project progresses.

## Planned Website Features

- Professional homepage
- About the agency
- Travel destinations
- Tour packages and travel information
- Travel services
- Contact and enquiry form
- Responsive design for mobile, tablet, and desktop
- Search engine optimization (SEO)

*Note: These are planned features. They should only be marked as completed after implementation and testing.*
