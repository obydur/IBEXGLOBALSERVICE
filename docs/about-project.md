# About the Project – IBEX Global Service

## 1. Introduction

IBEX Global Service is a WordPress-based Travel Agency Website project currently under development.

The project aims to establish a professional online presence for a travel agency and provide visitors with useful information about travel services, destinations, and tour opportunities.

## 2. Project Objectives

The main objectives are:

- Build a professional travel agency website.
- Present travel services and destination information.
- Provide an easy way for visitors to contact the agency.
- Create a responsive user experience across different devices.
- Develop a website that can be maintained through WordPress.

## 3. Project Scope

The planned website scope includes:

- Homepage and agency introduction.
- About Us page.
- Travel services and tour packages.
- Destination information.
- Contact and enquiry functionality.
- Mobile-friendly website layout.
- Basic SEO configuration.

## 4. Target Audience

The website is intended for:

- People interested in travel and tourism.
- Individuals looking for travel-related services.
- Visitors researching destinations and tour packages.
- Potential customers who want to contact the travel agency.

## 5. Technology

The project uses WordPress as its Content Management System.

Additional technologies and tools may include:

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
- Elementor (if used)

## 6. Development Approach

The website is being developed in stages:

1. WordPress installation and configuration.
